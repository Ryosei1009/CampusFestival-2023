# 高松キャンパスフェスティバル 2023

**N高等学校・S高等学校 高松キャンパス、2 回目のキャンパスフェスティバルの告知サイト**

※ イベントは終了しました

</div>

高校在学中、高松キャンパスで開かれた 2 回目の「キャンパスフェスティバル」のために作った告知用の Web サイトです。
スローガン、タイムテーブル、会場へのアクセス、Zoom での参加方法を 1 ページにまとめました。

前年の [2022 年版](https://github.com/Ryosei1009/CampusFestival-2022) はテンプレートを使って作りましたが、今回はテンプレートを使わずに作っています。

## ページ構成

| セクション | 内容 |
| --- | --- |
| **Slogan** | スローガン「Takamatsu;Gate 異世代間のインタラクト」と、そこに込めた意味 |
| **TimeTable** | 各プログラムの時間を、プログラムごとの画像付きで表示 |
| **Access** | Google マップの埋め込みと、会場の住所、最寄り駅からの道のり |
| **Zoom** | 会場に来られない人のための Zoom の参加情報と QR コード |

### スローガンに込めた意味

今回のキャンフェスは「異世代間交流」と「タイムトラベル」を軸にしました。
親世代と子ども世代の違いを知り、新しい扉（ゲート）を開こう、という意味を込めています。
タイムトラベルを題材にしたゲーム「STEINS;GATE」をもとに、「交流する・互いに影響しあう」という意味の「インタラクト」を組み合わせました。

## 工夫したところ

### テーマに合わせたデザイン

スローガンのロゴを黒と白の 2 種類用意し、背景に合わせて使い分けました。
Adobe Fonts（Typekit）のフォントを使って、テーマの雰囲気に合う見た目にしています。

### 見ていて楽しい動き

- ページを開いたときは、読み込みが終わるまでスピナーを表示します
- スクロールすると、各セクションがふわっと下から浮かび上がるように表示されます
- スローガンの文章は文節ごとに区切り、画面幅が変わっても言葉の途中で改行されないようにしています

### 端末ごとに分けたレスポンシブ対応

スマートフォン（767px）、ウィンドウを半分にしたフル HD 画面（958px）、MacBook（1280px）を想定して、端末ごとに CSS ファイルを分けて調整しました。

### 作りやすさの工夫

- CSS をセクションごとのファイルに分けて、どこを直せばいいか分かりやすくしています
- フッターは別の HTML ファイルに分け、JavaScript で読み込んで表示しています
